# PROJECT ASSASSIN

An original Godot 4 stealth-sandbox prototype. The first greybox, **The Meridian: Missing Archive**, focuses on observing schedules, entering staff space, collecting records, and leaving without graphic action.

## Run

1. Install the standard Godot **4.4.1** editor (no .NET required).
2. Open this directory's `project.godot` in Godot and press F6/F5, or run `godot --path .`.
3. WASD moves, mouse looks, Shift runs, C crouches, E interacts, F5 saves, F9 loads, Escape releases the mouse; click to recapture. Bindings are in Project Settings → Input Map.
4. Find two gold records and return to the green exit. The blue marker provides a staff disguise. Check the HUD for access and awareness.

This is a **prototype, not a finished game**. Geometry and characters are primitive placeholders; no final artwork, animation, audio, complete persistence, full social stealth, or performance targets are claimed.
