# MakeHuman-derived CC0 character models

Eight human character models (Brad, Dale, Ellie, Gary, Hollis, Pickles, Rosa, Vance) are from HongJaeKIM94 and contributors in the RUBBERNECK character asset repository, pinned at commit `7c331e647229364f3160790fe158beedf132075a`: https://github.com/kimhongjae94/rubberneck-assets/tree/7c331e647229364f3160790fe158beedf132075a/models . The source README and asset inventory identify these as MakeHuman/MPFB-derived CC0 models. The source repository's CC0 license and its file-level source notes are preserved alongside the converted models. MakeHuman's system assets are independently identified as CC0 by the [MakeHuman FAQ](https://static.makehumancommunity.org/makehuman/faq/are_makehuman_files_free.html); this provenance does not grant rights over unrelated third-party assets. The upstream inventory notes specific model components and sources; inspect `SOURCE_ASSETS.md` before redistribution. Blender and MPFB are not used at runtime.

**Local modifications:** glTF Transform CLI 4.5.1 decoded `EXT_meshopt_compression`, dequantized `KHR_mesh_quantization`, and generated MikkTSpace vertex tangents to remove tangent-reconstruction portability warnings. `tools/convert_makehuman_glb.js` converts embedded WebP images into PNG (resizing only when either dimension exceeds 1024 px) and changes material alpha handling to `MASK` with cutoff 0.36. The model geometry, UVs, skin weights, skeletons, and image pixels (except resampling) were not intentionally altered. Rebuild with `tools/prepare_cc0_characters.sh` (requires curl, tar, npm, and Node.js 20 or newer). Tool versions are pinned in that script; verify output with project tests. glTF-Validator `2.0.0-dev.3.10` reports zero errors and zero warnings on all eight converted files. **Godot 4.4.1 import/runtime visual compatibility remains unverified**; presence of standard glTF features is not a substitute for runtime validation.

Original license is `CC0-1.0.txt`; upstream per-asset inventory is `SOURCE_ASSETS.md`. CC0 does not require attribution; voluntary credit: HongJaeKIM94 and the MakeHuman community.
