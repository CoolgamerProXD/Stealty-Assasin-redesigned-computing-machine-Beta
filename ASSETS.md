# Assets and dependencies

## Campaign expansion assets
The new assessment environment, robot silhouette and interface use procedural Godot primitives and text only; no external asset or licensed audio was imported. No footsteps, ambient loops, UI cues, dialogue recordings or transition sounds are implemented.

All visible geometry and materials are generated by project scripts from Godot primitives; no third-party art, sounds or fonts are included. The project requires Godot 4.4.1 or compatible Godot 4 editor/runtime, under the Godot Engine license (https://godotengine.org/license/). Godot itself is not included. `gdtoolkit` was used externally for syntax parsing, not as a project runtime dependency. No audio assets or animation libraries have been added. Any future external assets must include source, license, attribution and modification notes here.

Audit tooling: `gdcorrect` 0.2.0 was run externally as an offline static checker; it is not shipped or required by the game. Its separate license is CC BY-NC-ND 4.0.
